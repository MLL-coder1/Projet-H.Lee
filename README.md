# Projet-H.Lee

Refonte du site en React (Vite).

Démarrage en local

1. Installe les dépendances:

   npm install

2. Lance le serveur de développement:

   npm run dev

3. Ouvre http://localhost:5173

Branche de travail: `revamp-site`

Tu peux modifier le contenu de `src/pages/Home.jsx` pour changer le titre ou le texte d'accueil.
